# 目安箱 デザイン指針

## 目的

目安箱は、知らない誰かの悩みに出会い、自分の悩みもそっと置いていける場所である。画面はSNSや管理画面のように情報を並べるのではなく、**絵本の1ページを静かに開く体験**として設計する。

この文書は、画面の追加・実装・レビュー時に参照する共通の判断基準である。機能や状態の詳細は [画面詳細設計](./screens/README.md) を参照する。

## デザインコンセプト

### 絵本のような親しみやすさ

- 子ども向けに限定せず、どの世代にも親しみやすい、やわらかな手づくり感を作る。
- 画面の主役は投稿本文と利用者の行動であり、装飾は読書を邪魔しない量に抑える。
- 「評価する」「競う」雰囲気を作らない。リアクション、クイズ、履歴は、他者の声に出会ったことを表す。

### クレヨンと紙

- 見出し、短い操作名、しおりなどに、少し揺らいだ手書き・クレヨン風の表現を使う。
- 本文と入力欄は読みやすい標準的な日本語書体を使う。長文を手書き書体にしない。
- 背景は温かい白い紙、コンテンツは白い紙片・しおりとして表現する。
- 角丸は完全に均一にせず、わずかに不揃いにする。輪郭は細く、影はクレヨンで添えた程度に留める。
- 星、雲、月などの小さな落書きは、画面ごとに一つまでとする。意味を持たせず、操作対象にも使わない。

## 情報量と画面遷移

### 基本原則

- 1画面に見せる主要な行動は一つだけにする。
- 初期表示で、見出し、主コンテンツ、主要操作が画面内に収まることを基準にする。
- 情報をカード、バッジ、グラフで細分化しない。主役以外の情報は、折りたたみ・設定シート・次の画面へ退避する。
- 同時に複数の投稿、複数のクイズ設問、複数の集計を見せない。
- スクロールは基本的に使わない。フィードは「つぎの声」で1件ずつ進む。クイズは1通ずつ進む。

### スクロールを許容する例外

次の場合だけ、通常のページスクロールを許容する。横スクロール、無限スクロール、カード内スクロールは使わない。

- 投稿詳細の本文が画面高を超える場合
- 投稿フォームで、文字サイズの拡大やキーボード表示により入力欄・補助項目が画面高を超える場合
- エラーや安全上の注意を省略せず表示する必要がある場合
- フィード、クイズ、履歴を含む各画面で、画面高の不足または文字拡大により、必須情報・操作を省略せず表示するために必要な場合

この場合も、主要操作は内容の直後に置き、固定表示や不必要な重複を避ける。

## 画面共通の見た目

| 要素 | 指針 |
| --- | --- |
| レイアウト | 360px以上の1カラム。左右16〜24pxを基準にし、PCでもモバイル幅の読みやすさを保つ。 |
| 背景 | 温かい白の紙を基本にする。強いグラデーション、写真背景、装飾的なテクスチャの多用はしない。 |
| 色 | 主操作は落ち着いた紫を基本にし、黄色・ミント・桃色はしおりや紙片の補助色として控えめに使う。意味や状態を色だけで伝えない。 |
| 文字 | 本文は16px以上を目安にする。手書き書体は見出し・短いラベル・ボタンに限定し、本文・注記・入力内容では可読性を優先する。 |
| 操作 | タップ領域は44px以上を目安にする。押せる要素には言葉を添え、絵や装飾だけを操作にしない。 |
| 余白 | 情報を減らした代わりに余白を残す。要素を詰めて「かわいさ」を作らない。 |

## 共通コンポーネント

### 紙片

投稿本文、投稿入力欄、次の推薦は、少し不揃いな角丸の紙片として扱う。1画面に紙片を重ねすぎず、最も大切な内容だけを紙片に載せる。

### しおり

テーマ、クイズの参加者、履歴は、短い文字を載せたしおりで表現する。しおりの色は補助的な装飾であり、テーマや正誤を色だけで区別しない。

### リアクション

リアクションの名称は **「そっと寄りそう」** に統一する。返信、いいね、評価ではなく、「読んで受け取った」ことを表す一種類の操作とする。選択済み状態は、文言・件数・押下状態を組み合わせて示す。

### 表示設定

文字サイズ、原文・ひらがな・英語、読み上げはヘッダーの設定シートにまとめる。本文の近くに常時多くの切替を並べない。

## 画面ごとの適用

| 画面 | 主役 | 見せ方 |
| --- | --- | --- |
| フィード | 1件の投稿本文 | 1枚の紙片を読み、「つぎの声」で進む。投稿者情報は公開された年代・地域など最小限にする。 |
| 投稿 | 本文入力 | 大きな1枚の紙に書く。音声入力は「話して書く」とし、任意属性は折りたたむ。 |
| 投稿詳細 | 投稿本文 | 本文を最優先し、「そっと寄りそう」は本文の後に置く。表示設定はヘッダーの設定シートから開く。 |
| クイズ | 1通の投稿 | 3人をしおり、投稿を手紙として扱う。1通ずつ対応を選び、正誤より言葉を読む体験を優先する。 |
| 履歴 | 出会ったテーマ・地域 | 数字のダッシュボードではなく、読んだ声のしおりを並べる。集計とクイズ履歴は必要な分だけ開ける。 |

## アクセシビリティと安全性

- 手書き・クレヨン表現は装飾であり、本文の可読性、コントラスト、フォーカス表示を損なわない。
- ブラウザやOSの文字拡大時に、情報を隠したり横スクロールを発生させたりしない。
- 選択、送信、エラー、読み込み、リアクションの結果は、色以外に文言と操作状態で伝える。
- 匿名性と安全に関わる説明は、装飾的な言い換えだけにせず、短く明確な言葉で表示する。
- 送信中は重複操作を防ぎ、投稿・クイズの入力内容は通信失敗時にも保持する。
- 色味はこの指針の世界観を保ったまま、[デジタル庁デザインシステムのアクセシビリティ指針](https://design.digital.go.jp/dads/foundations/color/accessibility/)を参照する。本文・ラベル・アイコンは背景とのコントラスト比を4.5:1以上、操作要素の輪郭など文字以外の情報は3:1以上とし、キーボード操作時のフォーカス位置を常に見分けられるようにする。

## 避けること

- SNSのような無限フィード、複数投稿の密な一覧、通知バッジ、ランキング
- ダッシュボード型のカード群、過剰な数値・グラフ・フィルター
- 大きなキャラクター、画面を覆うイラスト、過剰なアニメーション
- 全文への手書き書体の適用、低コントラストな薄い文字
- 絵本風の装飾を理由に、必要な安全説明・エラー・操作名を曖昧にすること
