# フィード

## 目的

テーマを入口に、知らない誰かの声を1件ずつ読む。「そっと寄りそう」は投稿単位の操作とし、テーマ全体へのリアクションは設けない。

## テーマを選ぶ

- 「読む」画面の本の上に「テーマでえらぶ」を置く。通常ブラウザと未ログインのLINEミニアプリでも使える。
- 選択中は読書領域を「声のもくじ」に切り替える。テーマ名、短い説明、投稿件数を4テーマずつ表示し、前後のページへ移動できる。
- 件数は公開済み・分類完了の投稿件数であり、人数・リアクション数ではない。人気順に並べない。
- 性別・地域の条件を設定している場合は、同じ条件でテーマ一覧と件数を取得する。
- テーマを選ぶと、同じクラスタに属する投稿を最初から1件ずつ表示する。本を開いた状態で読み始める。
- 選択中のテーマ名と変更・解除操作を本の上に表示する。各投稿にも分類済みのテーマ名を添える。
- 選択中のクラスタIDをURLの`clusterId`に保持し、投稿詳細からフィードへ戻ったときも同じテーマを読み続けられるようにする。AI生成のテーマ名はURLへ含めない。
- 「テーマをしぼらず読む」「テーマを解除」はテーマ条件だけを解除し、性別・地域は維持する。
- もくじから「読んでいた声に戻る」を選ぶと、変更せず元の読書位置へ戻る。
- 本文の紙めくり・スワイプ・左右キー、投稿詳細、リアクションの既存操作を維持する。もくじを開いている間は左右キーで投稿をめくらない。

## 状態と例外

- テーマ取得中は読み込み状態、失敗時は再試行と読書へ戻る操作を表示する。テーマ一覧の失敗で通常の投稿閲覧を止めない。
- 条件に合うテーマがない場合は、その旨とテーマをしぼらず読む操作を表示する。
- 条件に合う投稿がない場合は「選んだ条件の声は、まだありません」と表示し、「すべての声を読む」でテーマ・性別・地域を解除できる。
- テーマが未生成、投稿の分類が未完了・失敗の場合はテーマ名を表示しない。条件未指定では原文を引き続き読める。
- フィルタ変更時はカーソルと表示位置をリセットする。新着・推薦のどちらでも絞り込みはサーバー側で実行する。
- もくじを開いたら見出しに、閉じたらテーマ変更ボタンにフォーカスを移す。選択中のテーマは文言と押下状態で示す。
- 長いテーマ名・説明は折り返す。360px幅・文字拡大では必要な縦スクロールを許容し、横スクロールやカード内スクロールを使わない。
