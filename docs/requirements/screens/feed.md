# フィード

## 目的

テーマを入口に、知らない誰かの声を1件ずつ読む。「そっと寄りそう」は投稿単位の操作とし、テーマ全体へのリアクションは設けない。

## テーマを選ぶ

- テーマは性別・地域と同じ読書条件として扱い、「読む」画面ふもとの「テーマ・性別・地域でえらぶ」の中で選ぶ。通常ブラウザと未ログインのLINEミニアプリでも使える。
- 条件の並びでは、テーマを性別・地域より先に置き、1行をまるごと使う。テーマ名は長く、2列に詰めると読めないため。
- 選択肢はテーマ名と「すべて」だけにし、紙の大きさ・めくる操作・画面の高さに干渉させない。
- 件数は公開済み・分類完了の投稿件数であり、人数・リアクション数ではない。人気順に並べない。
- 性別・地域の条件を設定している場合は、同じ条件でテーマ一覧を取得する。
- テーマを選ぶと、同じクラスタに属する投稿を最初から1件ずつ表示する。本を開いたまま読み続ける。
- 選択中のテーマ名は条件の見出しに表示する。各投稿にも分類済みのテーマ名を添える。
- 選択中のクラスタIDをURLの`clusterId`に保持し、投稿詳細からフィードへ戻ったときも同じテーマを読み続けられるようにする。AI生成のテーマ名はURLへ含めない。
- テーマの「すべて」はテーマ条件だけを解除し、性別・地域は維持する。
- 本文の紙めくり・スワイプ・左右キー、投稿詳細、リアクションの既存操作を維持する。

## 状態と例外

- テーマ取得中はテーマの選択欄を操作できない状態にし、失敗時は条件の並びに理由を示す。テーマ一覧の失敗で通常の投稿閲覧を止めない。
- 条件に合うテーマがない場合、選択肢は「すべて」だけになる。
- 条件に合う投稿がない場合は「選んだ条件の声は、まだありません」と表示し、「すべての声を読む」でテーマ・性別・地域を解除できる。
- テーマが未生成、投稿の分類が未完了・失敗の場合はテーマ名を表示しない。条件未指定では原文を引き続き読める。
- フィルタ変更時はカーソルと表示位置をリセットする。新着・推薦のどちらでも絞り込みはサーバー側で実行する。
- URLの`clusterId`から開いたなど、一覧に含まれないテーマを読んでいる場合も、選択肢からそのテーマを落とさない。
- 長いテーマ名は折り返す。360px幅・文字拡大では必要な縦スクロールを許容し、横スクロールやカード内スクロールを使わない。
