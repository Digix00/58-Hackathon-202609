# 学習履歴

## 目的

既読数の競争ではなく、自分がどのような声に触れたかを穏やかに振り返る画面にする。学習履歴はLINEミニアプリのLINEログイン済み利用者だけに提供し、通常ブラウザでは内容を表示せずLINEミニアプリで開く案内を表示する。LINEアカウント情報は表示しない。

## レイアウトと表示項目

| 領域 | 詳細 |
| --- | --- |
| はじめの振り返り | 今回出会ったテーマ・都道府県を、短い文章と一つのしおりで表示する。数値を主役にしない |
| 次の提案 | まだ読んでいないテーマ・都道府県を一つだけ提示し、フィードへ戻る導線を置く |
| もっと見る | テーマ・都道府県の傾向、読んだ数、クイズ履歴は必要な項目だけを次の画面で開く |

傾向、読んだ数、クイズ履歴を同時に並べない。各詳細画面でも、一度に扱う集計または履歴は一つにし、画面高や文字拡大で必須情報が収まらない場合だけ通常のページスクロールを使う。

## 状態と例外

| 状態 | 表示 | 次の行動 |
| --- | --- | --- |
| 履歴あり | はじめの振り返りと次の提案を表示する | 次の声を読む、または必要な詳細を開く |
| まだ履歴なし | 「最初の声を読んでみましょう」と表示する | フィードへ進む |
| 取得失敗 | 「履歴を読み込めませんでした」と表示する | 再試行する |
| LINE連携解除または利用不可 | 履歴を表示せず、利用できない理由を短く示す | LINEへ戻る |

LINE user ID、表示名、アイコン、アクセストークンなどの識別情報は表示しない。履歴を削除する必要がある場合の窓口や運用は、画面内の説明文ではなくプライバシー方針から参照できるようにする。
