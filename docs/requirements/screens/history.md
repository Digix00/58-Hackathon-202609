# 学習履歴

## 目的

既読数の競争ではなく、自分がどのような声に触れたかを穏やかに振り返る画面にする。履歴はLINEで確認済みの利用者に紐づけるが、LINEアカウント情報は表示しない。

## レイアウトと表示項目

| 領域 | 詳細 |
| --- | --- |
| 要約 | 今週読んだ投稿数、出会った地域数、クイズ回答数を3項目以内で表示する |
| 傾向 | 読んだテーマ、地域、公開属性の傾向を、短い文章とラベルで表示する |
| クイズ履歴 | 回答日、正答数、クイズへの再訪導線を表示する |
| 次の提案 | まだ読んでいないテーマ・地域を一つだけ提示し、フィードへ戻る導線を置く |

## 状態と例外

| 状態 | 表示 | 次の行動 |
| --- | --- | --- |
| 履歴あり | 要約、傾向、クイズ履歴を表示する | 次の声を読む |
| まだ履歴なし | 「最初の声を読んでみましょう」と表示する | フィードへ進む |
| 取得失敗 | 「履歴を読み込めませんでした」と表示する | 再試行する |
| LINE連携解除または利用不可 | 履歴を表示せず、利用できない理由を短く示す | LINEへ戻る |

LINE user ID、表示名、アイコン、アクセストークンなどの識別情報は表示しない。履歴を削除する必要がある場合の窓口や運用は、画面内の説明文ではなくプライバシー方針から参照できるようにする。
