# 起動

## 目的

通常のWebブラウザでは匿名セッションを開始して利用する。LINEミニアプリから開いた場合は、必要に応じてLINE利用を確認し、通知から開いた場合はクイズへ案内する。どの入口でも、LINEの表示名、アイコン、IDは画面に出さない。

## 入口と初期画面

| 入口 | 利用者の状態 | 初期画面 |
| --- | --- | --- |
| 通常のWebブラウザ | 匿名セッションを開始する | フィード `/` |
| LINEのリッチメニュー | LIFFを初期化できればLINE利用を確認する。失敗時は匿名セッションへ切り替える | フィード `/` |
| LINEのデイリークイズ通知 | 同上 | 今日のクイズ `/quiz/today` |

## 表示状態

| 状態 | 表示と操作 |
| --- | --- |
| セッション準備中 | ロゴとアプリ名を短く表示する。準備完了後に、起動元に応じた画面を開く |
| 利用可能 | フィードまたはクイズを表示する。匿名セッションでも主要機能を利用できる |
| LINEの利用確認に失敗 | 匿名セッションで利用を続ける。必要な場合だけ、LINEで開く案内を表示する |
| メンテナンス・通信失敗 | 再試行できる理由と操作を示す。入力途中の内容は失わない |

## 補足

- LINEで開く案内は、デイリークイズの配信を受け取りたい場合だけ表示する。
- 匿名セッションでは、セッションの有効期間内で投稿、既読、リアクション、クイズ回答、履歴を扱う。
- LINEを利用できる場合は、LINEの友だち状態に応じてクイズ配信と継続的な履歴を利用できる。
