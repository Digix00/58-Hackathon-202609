# 起動

## 目的

通常のWebブラウザでは、ログインなしで公開済み投稿を読む状態から始める。通常ブラウザでは投稿を含む操作を提供せず、操作を選んだ場合はLINEミニアプリで開く案内を表示する。LINEミニアプリでは未ログインでも投稿を読め、投稿、リアクション、既読記録、クイズ回答、学習履歴などを選んだときだけLINEログインへ案内する。ログイン後も投稿は他の利用者に匿名で表示する。

## 入口と初期画面

| 入口 | 利用者の状態 | 初期画面 |
| --- | --- | --- |
| 通常のWebブラウザ | 公開済み投稿を閲覧する | フィード `/` |
| LINEのリッチメニュー | LIFFを初期化し、未ログインでも閲覧できる | フィード `/` |
| LINEのデイリークイズ通知 | LIFFを初期化する。未ログインの場合はクイズ開始前にLINEログインを案内する | 今日のクイズ `/quiz/today` |

## 表示状態

| 状態 | 表示と操作 |
| --- | --- |
| セッション準備中 | 起動画面を表示する。準備完了後に、起動元に応じた画面を開く（[起動画面](#起動画面)） |
| 通常ブラウザで閲覧中 | フィードまたは投稿詳細を表示する。操作を選んだ場合は「LINEミニアプリで開く」を表示する |
| LINEミニアプリで未ログイン | フィードまたは投稿詳細を表示する。投稿、リアクション、クイズ、履歴を選んだときだけLINEログインへ進む |
| LINEログイン案内 | 「この操作はLINEでログインしてから使えます」と、ログインが必要な理由と投稿が匿名公開であることを短く示す。「LINEで続ける」を主操作、「読むだけ続ける」を副操作にする |
| LINEログイン後 | 選んだ操作へ戻る。ログイン失敗・中止時は、LINEミニアプリ内のフィードへ戻れるようにする |
| LINEログイン後、年代・性別・地域が未記入 | 投稿、リアクション、クイズ、履歴へ進む前に、[はじめの1ページ](./onboarding.md)を一度だけ表示する。フィードと投稿詳細の閲覧は続けられる |
| LIFF初期化失敗 | フィード・投稿詳細の閲覧は続けられる。初期化失敗と操作制限を案内し、投稿などの操作を選んだ場合はLINEミニアプリで開き直す案内を表示する |
| メンテナンス・通信失敗 | 再試行できる理由と操作を示す。入力途中の内容は失わない |

## 起動画面

LIFFの初期化を待つあいだに表示する画面である。待たせていることを知らせる画面ではなく、「いま誰かがこの本の題字を書いている」時間として見せる。

置くのは手書きの題字だけとし、これをアプリのロゴとして扱う。件数、今日の投稿数、一言など、めくる前に中身を予告するものは置かない。

| 幕 | 見せるもの |
| --- | --- |
| 下地 | JSの読み込み前から、温かい白の紙と約5mmの方眼を塗る。白い画面を出さない |
| 線 | クレヨンが左から入り、題字の下の波線を引きながら右へ渡る。題字はクレヨンが通った分だけ現れる |
| 色 | 引き終えたクレヨンに色が入り、シールが1枚ずつ貼られる |
| 待つ | 描き終えた絵のまま待つ。間が長くなったときだけ、待っていることを短い文で示す |
| 退場 | 絵とシールだけが持ち上がって抜け、方眼の紙が残る |

- 描き切るまでの時間を最低表示時間とし、準備が先に終わった場合は残りを早送りして収める。描いている途中で画面を切り替えない。
- 退場で紙を切り替えないので、続けて現れるフィードの本が同じ机の上に置かれたように見える。ここで本を開かない。ノートを開く動作はフィードの表紙が受け持つ。
- 起動画面が受け持つのはLIFFの初期化までとする。LINEログインの確認待ちは各画面の状態として扱う。
- 絵、シール、波線は装飾であり、押せる要素にも読み上げの対象にもしない。読み上げへ出すのはアプリ名と、待っていることを示す文だけとする。
- 動きを控える設定では、描き終えた一枚の絵として表示し、引く過程も貼る動きも持たせない。
- LIFFを初期化しない入口では準備待ちがないため、起動画面を表示せずにフィードを開く。

## 補足

- 通常ブラウザからLINEミニアプリへ移る案内は、投稿、リアクション、クイズ、履歴などの操作を選んだ場合に表示する。
- LINEログインから戻る先は、ログイン前に選んだ操作に限定し、ログインの中止・失敗で投稿データやLINE user IDをURLへ含めない。
- LINEログイン済みの利用者は、投稿、リアクション、既読記録、クイズ回答、学習履歴を利用できる。
- 年代・性別・都道府県は投稿に添える公開属性であり、読む声の選びかたにも使うため、初回ログイン後に一度だけ記入してもらう。記入後は設定画面から書き直せる。
