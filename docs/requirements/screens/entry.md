# 起動

## 目的

通常のWebブラウザでは、ログインなしで公開済み投稿を読む状態から始める。通常ブラウザでは投稿を含む操作を提供せず、操作を選んだ場合はLINEミニアプリで開く案内を表示する。LINEミニアプリでは未ログインでも投稿を読め、投稿、リアクション、既読記録、クイズ回答、学習履歴などを選んだときだけLINEログインへ案内する。ログイン後も投稿は他の利用者に匿名で表示する。

## 入口と初期画面

| 入口 | 利用者の状態 | 初期画面 |
| --- | --- | --- |
| 通常のWebブラウザ | 公開済み投稿を閲覧する | フィード `/` |
| LINEのリッチメニュー | LIFFを初期化し、未ログインでも閲覧できる | フィード `/` |
| LINEのデイリークイズ通知 | LIFFを初期化する。未ログインの場合はクイズ開始前にLINEログインを案内する | 今日のクイズ `/quiz/today` |

## 表示状態

| 状態 | 表示と操作 |
| --- | --- |
| セッション準備中 | ロゴとアプリ名を短く表示する。準備完了後に、起動元に応じた画面を開く |
| 通常ブラウザで閲覧中 | フィードまたは投稿詳細を表示する。操作を選んだ場合は「LINEミニアプリで開く」を表示する |
| LINEミニアプリで未ログイン | フィードまたは投稿詳細を表示する。投稿、リアクション、クイズ、履歴を選んだときだけLINEログインへ進む |
| LINEログイン案内 | 「この操作はLINEでログインしてから使えます」と、ログインが必要な理由と投稿が匿名公開であることを短く示す。「LINEで続ける」を主操作、「読むだけ続ける」を副操作にする |
| LINEログイン後 | 選んだ操作へ戻る。ログイン失敗・中止時は、LINEミニアプリ内のフィードへ戻れるようにする |
| LIFF初期化失敗 | フィード・投稿詳細の閲覧は続けられる。初期化失敗と操作制限を案内し、投稿などの操作を選んだ場合はLINEミニアプリで開き直す案内を表示する |
| メンテナンス・通信失敗 | 再試行できる理由と操作を示す。入力途中の内容は失わない |

## 補足

- 通常ブラウザからLINEミニアプリへ移る案内は、投稿、リアクション、クイズ、履歴などの操作を選んだ場合に表示する。
- LINEログインから戻る先は、ログイン前に選んだ操作に限定し、ログインの中止・失敗で投稿データやLINE user IDをURLへ含めない。
- LINEログイン済みの利用者は、投稿、リアクション、既読記録、クイズ回答、学習履歴を利用できる。
