# 投稿フォーム

## 目的

投稿の心理的負担を下げ、LINEログイン済みの状態で、他の利用者には匿名の悩みとして安全に投稿できるようにする。投稿をLINEアカウントに紐づけることで、投稿データをテーマ分類・推薦などのアルゴリズム改善に利用できる状態をつくる。

## 認証前の案内

通常ブラウザで `/post` を開いた場合は、入力フォームやログイン画面を表示せず、LINEミニアプリで開く案内を表示する。LINEミニアプリ内で未ログインの場合だけ、入力フォームの代わりにLINEログイン案内を表示する。

| 要素 | 内容 |
| --- | --- |
| 説明 | 「投稿するにはLINEで続けてください」と示す。公開時には名前・画像・LINEアカウント情報を出さず、投稿は匿名で表示されることを続けて伝える |
| 利用目的 | 投稿と任意属性を、プライバシー方針に示す範囲でテーマ分類・推薦などの改善に用いることを短く示し、詳細への導線を置く |
| 主操作 | 「LINEで続ける」。ログイン成功後はこの投稿フォームへ戻る |
| 副操作 | 「読むだけ続ける」。LINEミニアプリ内のフィードへ戻る |

## レイアウトと表示項目

| 順序 | 領域 | 詳細 |
| --- | --- | --- |
| 1 | 導入文 | 「うまくまとまっていなくても大丈夫」と短く伝える |
| 2 | 本文入力 | 必須。最大文字数、入力済み文字数、例文を表示する |
| 3 | 音声入力 | デモ必須。録音開始、文字起こし中、結果の確認・編集を同じ領域で扱う |
| 4 | 個別化の任意ステップ | 本文を確認した後に、年代、性別、都道府県を選べるようにする。次に読む声を自分に近づけるために使うこと、正確な年齢や住所は集めないことを短く示す。各項目に「回答しない」または「選択しない」を置く |
| 5 | 匿名・安全の注意 | LINEアカウント情報は他者へ表示されず、投稿は匿名で公開されること、個人情報や緊急相談に関する注意を示す |
| 6 | 投稿ボタン | 「この内容を匿名で投稿する」。送信中は文言を「投稿しています…」へ変え、無効化する |

性別の選択肢は「女性」「男性」「ノンバイナリー」「回答しない」を基本とする。地域の選択肢は都道府県だけとし、広域区分や住所の自由入力欄は作らない。

## 入力フロー

1. まず悩み本文だけを書いてもらい、「投稿内容を確認する」で次へ進む。属性の入力を、悩みを置くという主目的の前提にしない。
2. 本文を確認する意思を示した後で、「次に読む声を、あなたの今に少し近づけるため」と目的を伝え、年代・性別・都道府県をまとめて選べるようにする。
3. 「今回は入力せずに投稿する」を常に表示する。断る操作を隠したり、入力しないことに不利益があるような表現はしない。
4. 属性を推薦に使うことと、投稿に表示することは分ける。投稿への表示は未選択を初期値とし、利用者が明示的に選んだ場合だけ表示する。
5. 入力の有無にかかわらず投稿を完了できる。完了後は感謝を伝え、翻訳・クラスタリング・推薦の処理が後から進むことを知らせる。

この順序は、最初に感情的な負担が大きい本文入力へ集中してもらい、投稿意思が固まった後に追加情報を尋ねるためのもの。入力理由、選択の自由、利用範囲を同じ場面で伝え、納得して情報を渡せる状態をつくる。

## 入力検証と送信結果

| 条件 | 画面上の扱い |
| --- | --- |
| 本文が空白のみ | 入力欄の直下に「悩みをひとこと入力してください」と表示し、入力欄へフォーカスする |
| 文字数超過 | 入力中に残り文字数を示し、送信時は理由を明示する |
| 属性が不正 | 対象の選択欄の直下にエラーを表示する |
| 送信成功 | 完了状態に切り替え、「置いていってくれて、ありがとう」と表示する。フィードへ戻る導線を置く |
| 通信失敗 | 入力内容を保持し、「もう一度投稿する」ボタンを表示する |
| 外部処理失敗 | 投稿保存の成功を優先して知らせ、翻訳・クラスタリングは後から反映されると説明する |

## LINEログインと匿名性

- 投稿の作成・送信は、LINEログイン済みの利用者にだけ許可する。LINEログインで確認した利用者識別子は投稿の重複防止と投稿データの管理に用い、投稿と任意属性はプライバシー方針に示す範囲でテーマ分類・推薦の改善に用いる。
- 投稿完了画面・フィード・投稿詳細のいずれにも、LINEの表示名、画像、ID、LINE user IDを出さない。
- LINEログイン済みであっても、投稿ごとの年代・性別・都道府県は利用者が公開を選んだものだけを表示する。
