# 目安箱 画面詳細設計

## 共通方針

画面の見た目・情報量・スクロールに関する共通の判断は、[デザイン指針](../design-guidelines.md) を優先する。

目安箱は通常ブラウザからもLINEミニアプリからも利用できる。通常ブラウザは公開済み投稿の閲覧専用とし、投稿やリアクションなどの操作は提供しない。LINEミニアプリでは未ログインでも閲覧でき、投稿、リアクション、既読記録、クイズ回答、学習履歴などの操作を行うときだけLINEログインを必須にする。LINEログイン済みの投稿も、他の利用者には匿名で表示する。

- 通常ブラウザから操作を選んだ場合は、LINEミニアプリで開く案内を表示する。通常ブラウザ内でLINEログイン画面は開かない。
- LINEミニアプリ内の未ログイン利用者が操作を選んだ場合は、LINEログインの画面へ案内する。
- 投稿と任意属性は、プライバシー方針に示す範囲で、テーマ分類・推薦などのアルゴリズムを改善するために利用する。LINEアカウント情報を投稿本文や公開属性として表示しない。
- PC向けのグローバルナビゲーションは持たず、LINEミニアプリに合わせたヘッダーとモバイル下部ナビゲーションを使う。
- 1画面につき主要な行動は1つに絞る。送信中は二重送信を防ぐ。
- 色だけで状態を伝えず、文章、アイコン、ボタン状態を組み合わせる。

## 匿名性の扱い

LINE user IDやLIFFのトークンは、画面・URL・ログに表示しない。投稿者に関して表示できるのは、本人が選択した年代、性別、地域の広い区分だけである。LINEのアカウント情報を他ユーザーへ見せる機能、投稿者への返信、フォロー、共有は作らない。
