# 目安箱 画面詳細設計

## 共通方針

画面の見た目・情報量・スクロールに関する共通の判断は、[デザイン指針](../design-guidelines.md) を優先する。

目安箱は、すべてLINEミニアプリとして提供する。LINEの利用者識別は、投稿の重複防止、既読、クイズ回答、学習履歴にだけ使用し、画面上では匿名性を守る。

- LIFFの初期化と利用確認が終わるまで、投稿本文などのプロダクト情報を表示しない。
- 通常ブラウザで直接開いた場合は、本文を表示せず「LINEで開く」案内だけを表示する。
- PC向けのグローバルナビゲーションは持たず、LINEミニアプリに合わせたヘッダーとモバイル下部ナビゲーションを使う。
- 1画面につき主要な行動は1つに絞る。送信中は二重送信を防ぐ。
- 色だけで状態を伝えず、文章、アイコン、ボタン状態を組み合わせる。

## 匿名性の扱い

LINE user IDやLIFFのトークンは、画面・URL・ログに表示しない。投稿者に関して表示できるのは、本人が選択した年代、性別、地域の広い区分だけである。LINEのアカウント情報を他ユーザーへ見せる機能、投稿者への返信、フォロー、共有は作らない。
