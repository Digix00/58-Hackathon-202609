# 要件定義書

## 1. プロジェクト概要

### アプリ名

目安箱（仮）

### 解決したい課題

普段関わる人以外の悩みを知る機会や、自分の悩みを伝える機会がない。

### 開発目的

普段なら知ることがなかった悩みに出会えるようにする。

自分から発信する能力がない人でも、このアプリを使えば他人に自分が抱えている悩みを知ってもらうことができる。

高齢者、障害者などは、若者などが持っている悩みを知ることができず、自分の悩みを伝えることもできない。そんな課題を解決し、互いに助け合えるような街を作っていく。

#### 他人の悩みについて考え、理解を深める

一日一回配信されるクイズを通して、他人の悩みについて考える。インクルーシブな社会を作るきっかけにする。

### 想定ユーザー

老若男女

### 利用シーン

- 1人の時間に入力する
- LINEなどの公式アカウントから呼びかけが来たとき

### アプリの価値・独自性

- レコメンドの工夫
- 誰でも（子供でも、高齢者でも、視覚障がい者でも）使えること
- 年齢や所属コミュニティの枠を超えて悩みを知ることができること

### ハッカソンのテーマとの関係

社会から排除されている人でも悩みを聞いてもらうことで、社会に受け入れられる一助になる。

## 2. スコープ

### 今回実装する機能

- ログイン機能（ログインなしでも使える）
- 悩み投稿機能
- 他人の悩みを見る機能
  - 悩みのクラスタリング
  - 英語翻訳、ひらがな変換
  - 音声入力、読み上げ
  - レコメンド
  - 悩みに紐づく位置情報や年齢の表示
- ログインユーザーが、投稿された悩みに対して知見を得た数を確認できる機能。そこから新しい知見をまとめる機能
- LINEミニアプリとしてのリリース
- 悩みを見て共感した場合に、共感ボタンを押せる機能
- LINE公式アカウントから一日一回クイズを送信し、回答できる機能
  - 本物の悩み1つと、AIで生成した悩み3つによる4択クイズ
  - クイズにはユーザーの情報（年齢、在住地域、性別）を表示する

### 最後まで実装しない機能

- 英語翻訳
- ひらがな変換
- 音声入力・読み上げ
- LINEリリース
- 位置情報
- 悩み同士のつながり

### MVPの範囲

- 悩みの投稿と閲覧のみ

### デモで見せる範囲

- すべて
- レコメンドを中心にする
- クラスタリング

## 3. ユースケース

### ユーザーが何をするか

- 悩みを投稿する
- 悩みを見る
- 自分の知見（成長）を見る

### 利用開始から終了までの流れ

- アプリを知った後、ログインせずに悩みを見たり投稿したりできる
- 悩みを見て共感した場合、共感ボタンを押せる
- 悩みの投稿者は、共感ボタンを押されたことを確認できる
- LINEミニアプリを前提とし、自動的にログインする

### 正常系の利用フロー

- LINEを前提としてログインする
- ログインの有無にかかわらず、悩みを投稿・閲覧できる
- ログイン状態にかかわらず、レコメンドが動作する
  - 一度見た投稿は表示されない、など
  - ログインしている場合は、パーソナライズされたレコメンドを行う

### 例外・失敗時のフロー

現時点では未定義。
